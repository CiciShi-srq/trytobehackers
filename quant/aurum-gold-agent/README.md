# Aurum 黄金因子研究台 v0.2

浏览器内计算的量价、舆情和简化缠论研究工作台。继承早期ETF项目的时间隔离、费用记账和结果留痕思路，本版改为单黄金ETF时间序列研究，不把高度相似ETF之间的排名当成广泛横截面选股证据。

## 运行

无需安装依赖。Node.js 18+ 运行测试：

```bash
node --test tests/engine.test.cjs
python -m http.server 8766 --directory dist
```

打开 http://localhost:8766 。静态网页在本地浏览器计算，导入CSV不会上传。无public-sample.js时回退为固定种子合成数据。仓库不包含iFinD账号、密码或授权数据。

## 功能

- 英文/中文OHLCV CSV，检查日期、重复值、OHLC约束和正数；至少65条日线。
- 8个量价指标：5/20日动量、5日反转、20日低波动、量能异常、Amihud近似、振幅、收盘位置。
- 新闻CSV：标题去重、词典或用户给分、净分与关注度；最早次日可用。缺新闻时不虚构新闻。
- 自动模式只按前60%训练期的绝对Rank IC筛选最多3个因子；有效标签至少30个，排除动量/反转重复组合。后40%测试，选择理由保存在selectionAudit。
- 多头/现金研究回放、买卖费用、持有基准、净值与账本。信号t-1收盘已知，在t收盘参考成交，计算t到t+1收益。
- 包含合并、确认分型、交替笔、三笔交集、MACD背驰候选；支持历史截止日回放。末端笔可被后续极值修订，不作为因子回测信号。
- 研究断言手工登记/变更、浏览器本地审计、导出JSON/CSV/独立HTML。

## 数据契约

行情：date,symbol,open,high,low,close,volume,amount。amount可选；缺失时流动性分母用close×volume近似，必须核对量单位。导入时填写来源、价格口径、真实/合成声明；声明不等于独立验证。新闻：published_at,title,source,sentiment（[-1,1]，可不填）。不保存导入的行情/新闻文件到服务器；断言文本和操作记录保存在本浏览器localStorage，可能包含研究者手写内容。

默认部署样本来自腾讯财经公开日线接口，非iFinD，区间2025-11-07至2026-11-06，共242条。公开GitHub源码不附带该行情快照；本地部署可按自己的数据许可提供样本。iFinD用户虽已登录，但本次桌面抓取异常，尚未成功导出终端数据；不能声称已接入iFinD自动下载。真实舆情样本尚缺，舆情入口和词典为可运行工具，不代表已完成舆情有效性验证。

## 缠论规则的边界

本版为明确约定的子集，不是完整缠论复刻或数学证明：没有特征序列线段递归、多级别走势分解或一二三类买卖点认证。分型发生与确认分开记录；同类末端可修订。三笔交集不等于经严格线段/次级别走势定义的全部中枢。MACD面积减弱仅作启发式候选。不可将事后完整结构图回填到历史交易决策。

## 验证与限制

15项Node测试覆盖CSV、新闻去重与滞后、训练方向与自动选择隔离、同日信号防前视、费用、末期平仓、分型确认及边界。约一年单标的样本不足以证明泛化；IC是时间序列相关，不是横截面IC。多次查看测试结果后改参数，测试不再独立。未包含真实成交、交易单位、最低佣金、停牌/涨跌停限制、市场冲击、全文语义模型、LLM或后台计划任务。
