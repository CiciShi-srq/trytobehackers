# Changelog

## 0.1.0 — 2026-10-19

- 首个研究演示版本：6 个固定因子，7 个候选策略，训练/验证/独立测试。
- 支持 Rank IC 审计、模型冻结、含双边费用的历史回放及同池等权基准。
- 输出中文 HTML 报告、成交/净值 CSV 和未成交研究目标。
- 提供 AKShare ETF 后复权行情适配器（在线端点尚未验证）。
- 增加有限数值/整数参数校验、过大预热窗口与非法冻结模型检查。
- 报告标签周期随实际配置显示，支持 `--version`。
- 增加可复现 ZIP、SHA256 校验、GitHub 自动测试与版本发布流程。
- 明确区分合成演示、真实行情验证和实际可执行交易。
